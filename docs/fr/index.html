Calaméo PDF Downloader

Téléchargez les publications Calaméo complètes en PDF, directement depuis le lecteur. L’extension réactive les boutons natifs Télécharger et Imprimer lorsqu’ils sont désactivés.

Installer sur Firefox Télécharger pour Chromium Voir le code sur GitHub

Firefox 140+ · Chrome · Edge · Brave (testé)

Gratuit pour toujours · Projet libre sous GNU AGPL v3.

Fonctionnalités

  • Télécharge toutes les pages en un seul PDF depuis le bouton Télécharger du lecteur Calaméo.
  • Active les boutons Télécharger et Imprimer lorsque le lecteur les désactive.
  • Ouvre la boîte d’impression habituelle du navigateur avec le document complet, y compris avec Ctrl+P.
  • Assemble le PDF localement dans le navigateur, sans compte ni convertisseur tiers.

Confidentialité et limites

Les pages sont récupérées depuis les serveurs d’images Calaméo et assemblées dans le navigateur. Le PDF contient des images des pages ; le texte OCR, les liens et les médias interactifs ne sont pas ajoutés.

Utilisation

Ouvrez une publication sur calameo.com/read/…, puis utilisez le bouton Télécharger pour enregistrer toutes les pages. Imprimer ou Ctrl+P ouvre la boîte d’impression du navigateur. Pour ne garder que certaines pages, choisissez « Enregistrer au format PDF » et indiquez les numéros de page.
